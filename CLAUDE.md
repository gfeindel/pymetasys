You are a full stack engineer tasked with creating a Python web app to control a Johnson Controls Metasys system. The system is controlled via a VT100 serial terminal. The serial terminal is accessible as a raw socket over the network via a serial-to-IP bridge.

The configuration and operation of the system are explained in the [user guide](./CF-Terminal-User-Manual.pdf). The manual is 367 pages, so only read it if the implementation plan does not answer your question.
